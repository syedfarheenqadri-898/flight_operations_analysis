# Flight Operations Data Analysis

## Overview

This project analyzes a Flight Operations dataset using Python, NumPy, and Pandas. The analysis follows a complete data analysis workflow to understand flight operations and identify meaningful patterns.

## Concepts Used

- NumPy arrays
- Indexing and slicing
- Mathematical operations
- Pandas Series and DataFrames
- CSV import and export
- Data selection and filtering
- Sorting
- GroupBy and aggregation
- apply() and lambda functions
- Datetime operations
- Merge, Join and Concatenate
- Data cleaning and transformation

## Key Analysis

The project examines flight delays, passenger volumes, ticket prices, weather conditions, flight status, travel classes, and monthly flight activity.

## Files

- `Day10_Flight_Operations_Analysis.ipynb` – Complete analysis notebook
- `Day10_Flight_Operations_Dataset.csv` – Original dataset
- `Flight_Operations_Cleaned.csv` – Cleaned and transformed dataset

- Python
- NumPy
